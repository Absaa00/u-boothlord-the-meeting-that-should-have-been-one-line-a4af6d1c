# The Meeting That Should Have Been One Line

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c)

Entry for the [make.fun bounty](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c):
write the single sentence that could have replaced an entire pointless
meeting. No context, no explanation, no setup — just the line.

## The line

> Nobody read the email that already decided this, so this meeting is just the live audiobook version of a decision we already made.

## How it works

`main.py` is deterministic and uses no network: it validates the line
(1–200 characters, one sentence, no whitespace-only) and writes it
exactly, with no trailing newline, to `/output/entry.txt`.

```sh
python3 main.py
```
